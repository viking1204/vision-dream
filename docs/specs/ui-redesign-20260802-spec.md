# VisionDream UI 重设计方案（2026-08-02）

> 基于真机（OnePlus 6 / PJZ110）ADB 截图与 `ModelListScreen.kt`、`ChatGenerationScreen.kt`、`AssetHistoryCollection.kt` 源码现状整理，供开发工程师落地。
> 设计总原则：**紧凑、一致、可访问（WCAG AA）**。去掉占满宽度的大输入框/大按钮，改用「图标触发浮层 + 底部功能区 + 标签过滤」的紧凑范式。

---

## 0. 现状问题（来自真机截图）

| 页面 | 当前问题 |
|------|----------|
| 模型列表 | 顶部 `TopAppBar` 右侧一个绿色实心设置圆钮；正文里 3 个占满宽度的元素：「搜索本地模型」输入框、「搜索模型仓库」按钮、「添加自定义模型」按钮。竖向空间浪费严重，且「搜索本地模型」与下方模型仓库搜索语义重复。 |
| 创作页 | 点击生成后 `isGenerating=true` 经 `enabled = !isGenerating` **禁用了整个输入区**（提示词输入框、负面提示词、模型选择按钮、发送按钮）。用户无法在生成过程中继续输入或排队。发送按钮是单个带文字的 `FilledIconButton`。 |
| 资产列表 | 已有长按选择模式与信息面板（`onShowInfo`），但**缺少「把该资产生成参数设为当前模型默认」的入口**。 |

## 1. 紧凑型设计 Token

在现有 Material 3 基础上收紧密度（沿用应用主色：绿色 `c-green` 作主操作、紫色 `c-purple` 作发送）。

| Token | 值 | 说明 |
|-------|----|------|
| 基础间距 | `4dp` | 单一基准 |
| 间距档位 | `4 / 8 / 12 / 16 / 24 dp` | 组件内用 8/12，区块间用 16/24 |
| 圆角 | `sm=8` `md=12` `lg=16` | 输入框/卡片用 md，composer 用 lg |
| 图标按钮尺寸 | `36dp`（最小触摸 44dp 用 padding 补足） | 替代原来的 48dp 大钮 |
| 普通图标 | `20–22dp` | 行内/列表图标 |
| 字号 | `12 / 13 / 14 / 16 / 20` | 正文 13–14，标题 16/20，辅助 12 |
| 行高 | `1.4–1.6` | 紧凑但不挤 |
| 主色 | 绿 `#639922`(600) | 主操作 / 选中 |
| 发送色 | 紫 `#534AB7`(600) | 发送 / 入队 |
| 表面 | `surface` / `surfaceVariant` | 浮层与卡片 |
| 危险 | 红 `#A32D2D` | 删除 / 失败 |
| 对比 | 正文 ≥ 4.5:1，大字 ≥ 3:1 | WCAG AA |

**触摸目标**：所有可点击图标按钮实际命中区 ≥ `44×44dp`（用 `Modifier.size(36dp).clickable` + 外层 `48dp` 命中区，或 `IconButton(Modifier.size(44.dp))` 内放 22dp 图标）。

## 2. 无文字图标语义表（关键）

所有图标**不带文字**，必须能通过形状传达意图；且必须提供 `contentDescription` 供无障碍。

| 图标（Material Symbols） | 含义 | 使用位置 |
|--------------------------|------|----------|
| `search`（放大镜） | 搜索本地模型 | 模型列表右上图标行 |
| `language` / `public`（地球） | 搜索模型仓库（远程） | 模型列表右上图标行 |
| `add`（加号） | 添加自定义模型 | 模型列表右上图标行 |
| `tune` / `settings`（齿轮） | 设置 | **底部功能区**（不再放右上） |
| `sell` / `label`（价签） | 按标签过滤 | 模型列表过滤条入口 |
| `sliders`（滑块） | 负面提示词 | 创作 composer 底栏 |
| `image` / `add_photo_alternate` | 图生图 / 附参考图 | 创作 composer 底栏 |
| `auto_fix_high`（魔棒） | 局部重绘 / 放大模式切换 | 创作 composer 底栏（或模式段控） |
| `send`（纸飞机，自动镜像） | 发送 / 入队 | 创作 composer 右下 |
| `stop`（方块） | 停止当前任务 | 生成中替代发送，或队列内 |
| `playlist_add` / `queue`（队列） | 任务队列面板 | 创作页常驻条 |
| `check_circle`（对勾圆） | 设为当前模型默认 | 资产信息面板 |
| `delete`（垃圾桶） | 删除 | 队列 / 模型卡 |
| `drag_indicator`（拖动点） | 拖拽排序 | 队列项 |
| `clear_all`（清空） | 清空队列 | 队列面板顶栏 |

## 3. 模型列表页（需求 1）

### 3.1 顶部彻底精简
- `TopAppBar` 仅保留：左侧标题「模型」+ 副标题「已安装 N 个模型」（副标题用 12dp 次级色）。
- **右上角改为一个紧凑图标行**（3 个无文字 `IconButton`，间距 4dp）：`search` → `language` → `add`。尺寸 36dp。
- 原「右上绿色设置圆钮」**移除**，下沉到屏幕最底部「功能区」（见 3.4）。

### 3.2 标签过滤条
- 标题下方一条**横向滚动的 `FilterChip` 行**：`全部` + 派生标签（如 `动漫` `写实` `SD1.5` `图生图` `局部重绘` `CPU` `NPU`）。
- 选中某个标签 → 本地模型列表实时过滤（多选 OR，可加「全部」复位）。
- 过滤条右端放一个 `sell` 图标按钮，点击可展开「标签多选浮层」（支持跨类目组合）。

### 3.3 三处输入 → 图标触发浮层
点击右上 3 个图标，分别弹出 **`ModalBottomSheet` / `Popover`**（而非常驻输入框）：

| 触发图标 | 浮层内容 |
|----------|----------|
| `search` 搜索本地 | 一个搜索 `TextField`（自动聚焦）+ 上方复用同一条标签 `FilterChip` 行；实时过滤本地模型。关闭即收起。 |
| `language` 搜索仓库 | 仓库搜索 `TextField` + 仓库来源下拉 + 标签过滤；展示远程结果列表。 |
| `add` 添加自定义 | 自定义模型表单（名称、路径/URL、类型、后端 CPU/NPU 等），即原「添加自定义模型」表单。 |

> 浮层在 `LocalContext` 内用 `ModalBottomSheet` 承载；表单复用现有 `ModelListScreen` 内的 `OutlinedTextField` 实现，只是从「常驻」改为「按需弹出」。

### 3.4 底部功能区
- 屏幕最底部（在 `BottomNav` 之上或合并进 `BottomNav` 的溢出区）新增一条**功能区**，仅放 `tune`（设置）一个图标（无文字）。
- 点击展开设置（`showSettingsDialog` 已有，逻辑不变），只是入口位置从 `TopAppBar` 移到这里。
- 其余主 Tab（工作台/创作/资产/模型/服务）保持 `BottomNav` 不变。

### 3.5 模型卡片（紧凑规格）
每张卡：
- 左：模型名（14dp/500）+ 一行描述（12–13dp 次级，单行省略）。
- 标签行：`AssistChip`/`SuggestionChip` 显示派生标签（小号）。
- 右侧信息：大小 `1.2GB`、尺寸 `128~512`（12dp 次级，可并入一行）。
- 操作：`play`（设为当前/开始）、`edit`（重命名）、`delete`（删除）三个 32–36dp 图标按钮，常驻行尾，**不再用大按钮**。

## 4. 创作页输入区（需求 2、3）

### 4.1 不禁用输入（需求 2）
- 移除 `enabled = !isGenerating` 对**输入控件**的绑定：提示词 `OutlinedTextField`、负面提示词、模型选择按钮在生成中**保持可编辑**。
- 仅在**真正需要互斥**的瞬间才禁用（如模型切换中），而不是整个生成周期。
- 发送按钮：生成中点击 = **把当前 prompt 加入任务队列**（配合需求 4），而非禁用。

### 4.2 ChatGPT / WorkBuddy 风格 Composer
底部一个**圆角容器（`shape=lg`，`surfaceVariant` 背景，0.5dp 描边）**，内部：

```
┌───────────────────────────────────────────┐
│ 提示词多行输入框（占位“描述你想生成的内容…”） │
│                                    [图生图][⊕] │  ← 内联小图标（可选）
├───────────────────────────────────────────┤
│ [模型:Anything V5·CPU▾] [负面] [参考图] … [➤] │  ← 底栏：图标按钮无文字
└───────────────────────────────────────────┘
```
- **顶部**：prompt `BasicTextField`/`OutlinedTextField`（多行，随内容高度增长，最大 ~6 行后滚动）。
- **底栏**（一行，图标按钮无文字，间距 8dp）：
  - `模型选择`：一个 chip 显示「模型名·后端」，点击弹出**模型选择 popover**（见 4.3）。
  - `sliders` 负面提示词开关。
  - `image` 附参考图（图生图）。
  - `auto_fix_high` 模式段控（文生图/图生图/局部重绘/放大，用 `SegmentedButton` 或下拉）。
  - 右侧弹性空白后：`send` 发送/入队（紫色 `FilledIconButton`）。生成中该钮变为 `stop` 或显示「已入队 N」。
- 整个 composer 常驻底部，上方为对话/历史区（现状保留）。

### 4.3 模型选择 Popover（与外部一致）
- 点击底栏「模型」chip → 弹出 `ExposedDropdownMenu` 或 `ModalBottomSheet`：
  - 顶部一个**搜索框 + 标签 `FilterChip` 行**（复用模型列表的标签过滤逻辑）。
  - 列表项：模型名 + **一行描述** + 标签 chips + 后端（CPU/NPU）。与外部模型列表**同一组件**，保证一致。
  - 单选，选中即回填底栏 chip。

### 4.4 负面提示词
- `sliders` 激活后展开一个内联区（或复用现有负面提示词 BottomSheet），不再用占满宽度的常驻按钮。

## 5. 任务队列（需求 4）

### 5.1 行为
- 新增「生成任务」概念 `GenerationTask`；当前若有任务 running，新提交的任务**进入队列后台执行**（不阻塞输入）。
- 队列按「智能排序」可聚合同模型任务，减少模型重载切换开销。

### 5.2 常驻队列条（创作页底部）
- composer 上方一条 **slim 条**：左 `queue` 图标 + 文案「队列 N · 当前：模型名 xx%」+ 右侧进度；点击展开面板。
- 无任务时条可隐藏或显示「队列空」。

### 5.3 队列面板（ModalBottomSheet / 独立页）
- 列表项（每项一行或两行）：
  - 状态点：`queued`（灰）/ `running`（绿，带线性进度）/ `done`（绿对勾）/ `failed`（红）。
  - 模型名 + 后端 +  prompt 摘要（单行省略）。
  - 右侧：`drag_indicator`（拖拽排序）、`delete`（删除）。
- 顶栏：`clear_all`（清空队列）+ 开关「智能排序（按模型聚合）」。
- 可编辑：拖拽重排顺序、删除单条、一键清空。
- 智能排序：开启时按 `modelId` 分组连续排列（同模型相邻），可在用户手动拖拽后保留手动顺序或用「重新聚合」按钮复位。

### 5.4 状态机（供开发）
```
queued → running → done
              └──→ failed（可重试/删除）
```
- 单并发执行（或按设备能力限定并发数）；`running` 仅 1 个，`queued` 任意。
- 进度回传驱动队列条与面板进度。

## 6. 资产列表（需求 5）

### 6.1 入口
- 资产页已有长按选择（`onLongClick` → `isSelectionMode`）与信息面板（`onShowInfo` → 参数面板，含 `item.params.prompt/negativePrompt/width/height/...`）。
- 在**信息面板底部**新增按钮：`check_circle` 「设为当前模型默认」。
- 选择模式下，选中**单条**时顶栏出现该按钮（多选时禁用并提示「仅支持单条」）。

### 6.2 行为
- 点击后将 `item.params` 写入**当前选中模型**的默认值（覆盖 prompt、negativePrompt、width、height、steps 等调度参数）。
- 成功 `Snackbar`：「已将参数设为 [模型名] 默认值」；若未选模型则提示先选模型。
- 危险操作无，但覆盖默认可加一次轻确认（可选）。

## 7. 交互状态与可访问性
- 所有图标按钮 `contentDescription` 必填（见第 2 节）。
- 触摸目标 ≥ 44dp；浮层/弹窗焦点陷阱（`Pane`/`BottomSheet` 自带）。
- 深色模式：所有 token 走 `MaterialTheme.colorScheme`，不写死色值。
- 减少动效：浮层/队列动画尊重 `reducedMotion`。
- 队列状态用颜色 + 文案双通道（不只靠颜色）。

---

## 8. 数据模型建议（供开发参考，非强制）
- `GenerationTask`：`id, modelId, prompt, negativePrompt, paramsJson, status, progress, createdAt, order`。
  - 落库建议：Room 新表或用现有后台任务表扩展；UI 状态由 `StateFlow<List<GenerationTask>>` 驱动。
- 模型标签派生：定义规范标签词表 + 规则提取（关键词匹配 description，如含「动漫/二次元」→`动漫`；含「realistic/写实」→`写实`；`SD1.5`→`SD1.5`；支持能力字段 → `图生图`/`局部重绘`；`runOnCpu`→`CPU` 否则 `NPU`）。标签可缓存到模型元数据，避免每次重算。
- 当前模型默认值：复用现有 `GenerationDefaults`（按 modelId 维度）写入。
