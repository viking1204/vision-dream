# VisionDream UI 重设计 — 需求捕获（ui-redesign-20260802）

> 来源：用户 2026-08-02 提出的 5 项优化点（基于真机 OnePlus 6 / PJZ110 截图与现状源码）。
> 关联规格：`docs/specs/ui-redesign-20260802-spec.md`
> 红线（贯穿全程，违反即 P0）：Room schema 固定 v10；`BackgroundGenerationService` 时序不变；OpenAI/MCP/Remote 协议语义不变；`model_run` 路由语义不变。

## 1. 业务目标
把当前偏「大输入框 / 大按钮 / 占满宽度」的界面，重构为**紧凑、一致、可访问（WCAG AA）**的范式：图标触发浮层 + 底部功能区 + 标签过滤，并补齐「任务队列」与「资产参数设为模型默认」两项能力。

## 2. 角色与场景
- 移动端文生图用户：在手机上快速选模型、发提示词、看图。
- 多模型囤积用户：本地装很多模型，需要按标签快速筛选。
- 批量创作用户：一次想排多个生成任务，不想被单次生成阻塞输入。

## 3. 范围边界
### 3.1 本次范围
1. 模型列表页紧凑化（搜索/仓库/自定义 三个输入框 → 图标触发浮层；设置下沉底部功能区；本地搜索支持按 tag 过滤；模型标签基于描述派生）。
2. 创作页点击生图后**不禁用**输入区域。
3. 创作页输入区重设计为 ChatGPT/WorkBuddy 风格（底部圆角 composer，按钮置于底栏且无文字；模型列表显示描述 + 标签快速过滤）。
4. 新增**任务队列**：后台执行、可见当前任务、可编辑/清空、按模型智能排序聚合。
5. 资产列表支持选择单个资产，将其生成调度参数设为当前模型默认值。

### 3.2 不在本次范围
- 不改生成引擎、模型格式支持、协议后端。
- 不改 Room 数据库 schema（任务队列持久化走 DataStore，不新增 Room 表）。
- 不改 `BackgroundGenerationService` 内部时序；队列仅在其既有调用入口之上做编排。

## 4. 验收口径
| 编号 | 验收项 | 可观测标准 |
|------|--------|------------|
| AC-01 | 模型列表紧凑 | 顶部无绿色设置圆钮；右上 3 无文字图标（search/language/add）；设置入口在底部功能区。 |
| AC-02 | 本地搜索浮层 + 标签过滤 | 点 search 图标弹出浮层可实时过滤本地模型；标签 FilterChip 行可按派生标签过滤。 |
| AC-03 | 创作输入不禁用 | 生成中提示词/负面/模型选择钮仍可编辑；发送钮变为「入队」。 |
| AC-04 | ChatGPT 风格 composer | 底部圆角 composer；底栏图标钮无文字；模型选择 popover 含描述 + 标签过滤。 |
| AC-05 | 任务队列 | 有运行中任务时新任务入队后台执行；创作页有常驻队列条；面板可拖拽/删除/清空/智能排序。 |
| AC-06 | 资产设为默认 | 资产信息面板（或单条选择）出现「设为当前模型默认」入口，写入当前模型默认参数。 |
| AC-07 | 可访问性 | 所有图标按钮有 contentDescription；触摸目标 ≥44dp；深色模式 token 走 colorScheme。 |

## 5. 待确认项（已产品确认，无外部阻塞）
- 图标语义表已定（见 spec 第 2 节），无歧义。
- 标签派生采用规则提取（关键词匹配描述），不引入 ML 推理。
- 任务队列持久化采用 DataStore（JSON 信封），不触碰 Room v10。
- 智能排序默认开启，按 `modelId` 聚合连续排列。

## 6. 风险与依赖
- **R1（红线）**：任务队列不得新增 Room 表/迁移 → 必须用 DataStore 或独立文件存储。
- **R2（红线）**：队列执行必须复用既有生成触发路径，不得改动 `BackgroundGenerationService` 时序。
- **R3（设备）**：端到端「生成→出图→恢复」真机验证依赖能出图设备（PJZ110/K30）；OnePlus 6 仅能验 UI 不验出图（MNN/旧 CPU 不兼容，已知约束）。
