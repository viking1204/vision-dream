## 2. 验收口径

1. `./gradlew :app:compileDebugKotlin :app:testDebugUnitTest :app:assembleDebug :app:lintDebug :app:ktlintCheck :app:detekt` 全绿。
2. 图片消息在一条卡片内同时呈现：图片 + 提示词 + 模型名 + 耗时 + 3 个图标按钮。
3. 提交任务后消息列表不新增任何气泡；仅在图片产出（或报错）时新增。
4. 折叠底栏高度显著小于展开态。
5. 顶层页面（创作 / 资产 / 模型 / 工作台）无冗余标题栏占位。
6. OnePlus 13 真机安装启动无崩溃，UI 走查通过。

## 3. 红线约束（不得触碰）

- Room schema 固定 v10，本次不新增/修改任何 Entity 与迁移。
- `BackgroundGenerationService` 时序不变；队列 drain 逻辑（idle 边沿单发）不变。
- OpenAI / MCP / Remote 协议语义不变。
- `model_run` 路由语义不变。
- 推理仲裁 `InferenceArbiter` 获取/释放位置不变。
- 聊天历史 JSON 需向后兼容：旧版本无 `gt` 字段时必须能正常反序列化。

## 4. 边界与取舍

- 「合并成一个消息」采用**新消息不再产生 User 气泡**的方式；历史里已存在的 User 气泡保留渲染（不做数据迁移，避免破坏用户既有会话）。
- 删除按钮直接删除该条会话消息（不删磁盘资产），与既有批量删除语义一致。
- 折叠底栏改造只动 `VisionStudio.kt`，不改各页面 Scaffold 契约。
