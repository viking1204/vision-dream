## 业务目标

在不丢失既有用户数据、模型和资产的前提下，改善模型发现、来源追溯、下载去重和跨前后台工作连续性：本地创作用户可管理合规格式的自定义仓库、跨所有启用仓库检索模型、将手动导入模型关联回来源，并在重复下载/导入时获得一致的已安装关联提示；选择模型本身不触发立即加载。

## 场景链路

1. 用户新增或维护自定义仓库；首期仅接收现有 Hugging Face 格式或可配置同结构 JSON/目录索引，不抓取任意网页。
2. 用户搜索时，系统在所有启用仓库联合范围对显示名、`modelId`、描述、标签、后端/架构执行大小写无关分词包含匹配；`modelId` 精确匹配和名称前缀匹配优先，随后按相关度、名称排序。
3. 初始展示 30 项，加载更多每次增加 30 项；没有匹配时显示无匹配空态。某仓库网络或解析失败时，显示该仓库可重试错误，但其它仓库结果继续可用。
4. 用户选择模型不立即加载；手动导入时可搜索选择仓库模型建立 `repositoryId + remoteModelId` 来源关联，不选则为无来源本地模型。
5. 下载或导入时，来源 ID 命中标记已安装；否则文件指纹命中提示内容相同并关联已有模型；同名且来源、指纹均不同的模型允许并存。下架或改名后保留历史关联并展示来源失效。
6. 前后台切换后，恢复一级页面、筛选/排序、滚动位置、创作草稿、模型选择、高级参数和打开详情页；运行中任务以服务状态为准，不恢复旧弹窗。
